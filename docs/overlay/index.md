# Overlay

Windows and floating panels, built on native HTML (`dialog`, `popover`) so that they need no script.

| Component | Alias | Description |
| --------- | ----- | ----------- |
| [confirm-dialog](./confirm-dialog.md) | `x-zk-confirm-dialog` | Confirmation or notice in a dialog |
| [drawer](./drawer.md) | `x-zk-drawer` | Panel from a side |
| [dropdown-item](./dropdown-item.md) | `x-zk-dropdown-item` | Item of a dropdown |
| [dropdown](./dropdown.md) | `x-zk-dropdown` | List opened by a button |
| [modal](./modal.md) | `x-zk-modal` | Modal window |
| [popover](./popover.md) | `x-zk-popover` | Panel opened by a button |
| [tooltip](./tooltip.md) | `x-zk-tooltip` | Short description of an element |
