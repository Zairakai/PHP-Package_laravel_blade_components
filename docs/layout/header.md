# zk-header

> Renders a `<header>` element. Page or section header.

## Props

| Prop | Type | Default | Description |
|------|------|---------|-------------|
| `class` | `string|null` | `null` | CSS class(es) merged onto the element |

## Example

```blade
<x-zk-header class="my-class">
    Content goes here.
</x-zk-header>
```
