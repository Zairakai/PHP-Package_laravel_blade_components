# zk-grid-item

> Renders a `<div>` element. Grid cell — child of zk-grid.

## Props

| Prop | Type | Default | Description |
|------|------|---------|-------------|
| `class` | `string|null` | `null` | CSS class(es) merged onto the element |

## Example

```blade
<x-zk-grid-item class="my-class">
    Content goes here.
</x-zk-grid-item>
```
