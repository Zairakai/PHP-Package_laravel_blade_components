# zk-aside

> Renders a `<aside>` element. Secondary or sidebar content.

## Props

| Prop | Type | Default | Description |
| ---- | ---- | ------- | ----------- |
| `class` | `string\|null` | `null` | CSS class(es) merged onto the element |

## Example

```blade
<x-zk-aside class="my-class">
    Content goes here.
</x-zk-aside>
```
