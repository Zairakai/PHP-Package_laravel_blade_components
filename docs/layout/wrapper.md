# zk-wrapper

> Renders a `<div>` element. Full-width page wrapper with base class wrapper.

## Props

| Prop | Type | Default | Description |
| ---- | ---- | ------- | ----------- |
| `class` | `string\|null` | `null` | CSS class(es) merged onto the element |

## Example

```blade
<x-zk-wrapper class="my-class">
    Content goes here.
</x-zk-wrapper>
```
