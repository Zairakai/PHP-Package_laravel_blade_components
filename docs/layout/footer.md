# zk-footer

> Renders a `<footer>` element. Page footer.

## Props

| Prop | Type | Default | Description |
|------|------|---------|-------------|
| `class` | `string|null` | `null` | CSS class(es) merged onto the element |

## Example

```blade
<x-zk-footer class="my-class">
    Content goes here.
</x-zk-footer>
```
