# zk-nav

> Renders a `<nav>` element. Navigation landmark.

## Props

| Prop | Type | Default | Description |
|------|------|---------|-------------|
| `class` | `string|null` | `null` | CSS class(es) merged onto the element |

## Example

```blade
<x-zk-nav class="my-class">
    Content goes here.
</x-zk-nav>
```
