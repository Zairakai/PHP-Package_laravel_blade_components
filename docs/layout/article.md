# zk-article

> Renders a `<article>` element. Self-contained content block.

## Props

| Prop | Type | Default | Description |
|------|------|---------|-------------|
| `class` | `string|null` | `null` | CSS class(es) merged onto the element |

## Example

```blade
<x-zk-article class="my-class">
    Content goes here.
</x-zk-article>
```
