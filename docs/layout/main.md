# zk-main

> Renders a `<main>` element. Main content area of the page.

## Props

| Prop | Type | Default | Description |
| ---- | ---- | ------- | ----------- |
| `class` | `string\|null` | `null` | CSS class(es) merged onto the element |

## Example

```blade
<x-zk-main class="my-class">
    Content goes here.
</x-zk-main>
```
