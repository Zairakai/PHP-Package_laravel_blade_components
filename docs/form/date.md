# zk-date

> Renders an input of type `date`. All `zk-input` props accepted.
>
> Also available as `x-zk-date-picker`, the name that `@zairakai/vue-components` gives it.

See [zk-input](./input.md) for the full props reference.

## Example

```blade
<x-zk-date name="date" label="Date" />
```
