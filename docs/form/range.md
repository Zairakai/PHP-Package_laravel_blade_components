# zk-range

> Renders an input of type `range`. All `zk-input` props accepted.
>
> Also available as `x-zk-range-slider`, the name that `@zairakai/vue-components` gives it.

See [zk-input](./input.md) for the full props reference.

## Example

```blade
<x-zk-range name="range" label="Range" />
```
