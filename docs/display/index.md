# Display

Cards, badges, avatars and other blocks that show information.

| Component | Alias | Description |
| --------- | ----- | ----------- |
| [accordion](./accordion.md) | `x-zk-accordion` | Wrapper of expandable items |
| [accordion-item](./accordion-item.md) | `x-zk-accordion-item` | An item: a native `<details>` |
| [avatar](./avatar.md) | `x-zk-avatar` | Picture, initials or fallback |
| [badge](./badge.md) | `x-zk-badge` | Small label with a variant |
| [card](./card.md) | `x-zk-card` | Header, body and footer |
| [chip](./chip.md) | `x-zk-chip` | Compact tag with a remove button |
| [divider](./divider.md) | `x-zk-divider` | Separator, with or without a label |
| [empty-state](./empty-state.md) | `x-zk-empty-state` | Nothing to show |
| [stat](./stat.md) | `x-zk-stat` | A figure and its change |
